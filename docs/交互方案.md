# DeepSeek Harness 插件 · 交互方案说明 v0.1

> 目标：把"线性 AI 对话"变成"可视图上的节点对话"。一次问答 = 一个节点，节点之间的连线 = 上下文依赖关系。
> 本文档是给设计、前端、以及后续 Claude Code 做后端的共同基线。

## 一、整体形态

桌面浏览器横屏应用，单页、无页面级滚动条，占满视口。

- 三栏水平分割，宽度比例 **2 : 4 : 3**（左栏 / 画布 / 右栏），用 CSS Grid 实现。
- 最小可用窗口宽度 1280px；低于 1100px 时右栏可折叠为抽屉（V2）。
- 三栏各自独立滚动，画布区永远不出现滚动条（平移靠视图变换，不靠滚动）。

```
┌──────────┬──────────────────────┬─────────────┐
│  左栏 2  │       画布 4         │   右栏 3    │
│          │   （无限节点画布）    │ （对话详情） │
│ 新建对话  │                      │             │
│ 新建标签  │   ┌────┐    ┌────┐  │  用户问题    │
│ ──────── │   │节点├───▶│节点│  │  AI 回答     │
│ 对话列表  │   └────┘    └────┘  │             │
│          │                      │  [输入框]    │
└──────────┴──────────────────────┴─────────────┘
```

## 二、区域一（左栏，比例 2）

结构自上而下：

1. **「新建对话」按钮** — 创建一个新的整体对话，等价于新开一块画布，在下方列表中新增一项。
2. **「新建对话标签」按钮** — 在当前画布的视口中心创建一个空白节点（一次待提问的问答）。
3. **对话列表** — "新建对话标签"以下的全部区域，列出所有整体对话。

列表项显示：对话标题（默认「新对话 1/2/3…」，可重命名）、节点数量、最近更新时间。当前对话高亮。

行为约定：

- 点击列表项 = 切换画布。切换时保留每块画布各自的节点、连线、视图位置（缩放与平移）。
- 空白画布（无节点）时，画布中央显示引导文案与「新建对话标签」快捷入口。
- 只有一个整体对话时，删除对话按钮置灰（避免空态死锁）。

## 三、区域二（画布，比例 4）

### 3.1 坐标系与视图

- 无限画布，节点坐标存"世界坐标"，渲染时叠加视图变换 `translate(x,y) scale(s)`。
- 画布内容用一层容器承载，连线用其下方的 SVG 层绘制；两层共用同一变换矩阵，保证线随节点一起缩放。
- 缩放范围 **0.25x ~ 2.5x**，默认 1x。

### 3.2 平移与缩放

| 操作 | 效果 |
| --- | --- |
| 按住鼠标滚轮拖动（中键拖拽） | 平移整个画布 |
| 空格 + 左键拖动 | 平移整个画布（触控板友好，替代中键） |
| 滚动滚轮 | 以指针位置为锚点缩放 |
| 滚轮 + Ctrl，命中节点 | 只拖动该节点（按你的原始描述） |

缩放锚定公式：`s' = clamp(s * (1 - deltaY * 0.0015), 0.25, 2.5)`，锚点修正 `tx' = px - (px - tx) * s'/s`，保证指针下的画面内容不漂移。

补充：节点也支持"左键按住节点空白处直接拖动"，作为 Ctrl+中键的高频替代（两种都保留，不冲突，因为左键拖端口才是连线）。

### 3.3 节点样式

单个节点尺寸约 320 × 92px，圆角 10px，浅色卡片 + 细边框 + 轻投影。

```
●  ┌───────────────────────────────────┐  ●
   │  ○ ← 左端口                        │
   │  [ 标题输入框 · placeholder=首个问句 ]│
   │                            右端口 → ○ │
   └───────────────────────────────────┘
   左上角状态点：灰=空白 / 蓝闪=生成中 / 绿=已完成
```

- **左端口 / 右端口**：直径 12px 的圆点，hover 放大到 16px 并显示提示"拖出连线"。左端口 = 入，右端口 = 出。
- **中间标题**：一个无边框输入框，直接可编辑。默认值为该节点发起的第一句问题（截断到 24 字），未提问时显示占位符「未命名标签」。
- **选中态**：2px 高亮描边 + 更强投影，同时右栏切换为该节点内容。
- 节点内容过长不撑高，标题单行省略。

### 3.4 连线

- 左键从 A 的右端口拖到 B 的左端口（或 B 的任意端口）→ 生成一条有向边 A → B。
- 连线为三次贝塞尔曲线，目标端带箭头；hover 加粗高亮。
- **禁止成环**：若新连线会使图出现环路，拒绝创建并给出轻提示「不能连接到上游节点」。原因：上下文组装按拓扑序，成环无法定义顺序。
- 点击连线可选中，按 Delete 删除该连线。
- 自连（A → A）直接拒绝。

### 3.5 删除节点

右键节点 → 弹出确认浮层：

- 文案：「是否删除该对话标签？」
- 按钮：**取消**（默认焦点）/ **删除**
- 取消 → 完全回到原状态，无任何副作用。
- 删除 → 节点移除，**与它相连的所有入边和出边一并删除**，并检查被删节点是否为当前右栏选中项；是则右栏回到"未选择"态。

删除支持 Ctrl+Z 撤销（V1 建议做，成本低、误删代价高）。

### 3.6 其他画布交互

- 点击画布空白处 = 取消节点选中，右栏回到未选择态。
- 双击画布空白 = 在该位置新建一个空白节点（快捷方式，可选）。
- 画布左下角常驻小控件：缩放百分比、`适配`（全部节点入视野）、`100%`。

## 四、区域三（右栏，比例 3）

显示"当前选中节点"所代表的这一轮问答。三种状态互斥。

### 状态 1 · 未选择

- 居中文字：**「您还没有选择对话标签」**
- 副文案：「在画布中点击任意标签查看对话，或点击左侧「新建对话标签」开始一轮新的提问。」

### 状态 2 · 空白新标签 / 生成中

- 顶部：节点标题（可改）+ 状态标签「新会话」。
- 中部：空白，或用户气泡 + AI 气泡。
- 底部：固定输入区，多行文本框（默认 96px 高，最高占右栏 40%），提示「Enter 发送，Shift+Enter 换行」。
- 发送后：
  1. 用户气泡立即上屏（左对齐或右对齐，按现有 AI 产品惯例：用户右、AI 左）。
  2. 节点状态变 `streaming`，画布上该节点状态点转蓝闪。
  3. AI 气泡逐字流式追加，尾部带光标；生成期间输入框禁用，按钮变为「停止」。
  4. 完成 → 状态 `done`，输入框禁用并提示「本标签已完成，可编辑回答后继续在画布中新建下游标签」。

### 状态 3 · 已完成（可编辑上下文）

这是这个产品的核心差异点：**AI 的回答是可编辑的文本，编辑后的文本才是后续上下文真正读取的内容**。

- 用户问题块：只读展示。
- AI 回答块：默认渲染为文本块。
- 悬停回答块出现操作条：**编辑** / **删除本条**。
- 点「编辑」→ 文本块就地变成可编辑区域（保留原排版、行高 1.7、等宽可选），块上方出现「编辑中」标记。
- 保存：Ctrl+Enter 或点「保存」；放弃：Esc 或点「取消」。
- 已编辑过的回答块左上角显示「已编辑」小标记，操作条多一项「恢复原文」。
- 「删除本条」→ 回答置空，节点回退到 `draft` 状态但仍保留问题文本；用户可重新提问。
- 编辑只影响本地保存的 `answerEdited` 字段，`answerRaw` 永远保留原文，便于恢复与审计。

## 五、上下文组装规则（最关键的一条）

提问时，送往模型的上下文按以下规则拼装：

1. 目标节点为 N。
2. 取 N 的**全部上游祖先节点**：从 N 沿入边反向可达的所有节点（传递闭包，不含 N 自身）。
3. 按**拓扑序**排列；同层节点按画布坐标从上到下、从左到右作为稳定次序。
4. 每个祖先节点贡献一条历史：`{ 问题, 回答 }`，其中回答取 **answerEdited（若为空则取 answerRaw）**。
5. 若某个祖先节点的回答被用户清空，则该条历史被跳过（视为用户主动丢弃这段上下文）。
6. 最后追加 N 当前的 `question`，作为本轮请求。
7. 直接相连但不在祖先集合内的节点（下游、兄弟）不参与。

> 已确认（2026-11-22）：按"全部祖先 + 拓扑序"处理，不改为只取一跳邻居。

这条规则意味着：删掉某段 AI 输出、或改掉 AI 某句话，下游节点的回答就会变——这正是这个插件的价值所在，需要在 UI 上有可感知的反馈（下游节点标记「上下文已变更」为 V2）。

## 六、键位表

原则：鼠标是主路径，键盘是加速器；不劫持浏览器级快捷键（Ctrl+T / Ctrl+W / Ctrl+L 等）；输入框聚焦时，只有带修饰键的组合生效。

### 全局

| 按键 | 作用 |
| --- | --- |
| Ctrl/⌘ + N | 新建对话（新画布） |
| Ctrl/⌘ + Shift + N | 在当前画布新建对话标签 |
| Tab / Shift+Tab | 三栏焦点循环（左栏 → 画布 → 右栏） |
| Esc | 逐层关闭：编辑态 → 弹窗 → 连线中 → 取消选中 |
| Ctrl/⌘ + Z / Ctrl+Shift+Z | 撤销 / 重做（增删节点、连线、重命名、编辑回答） |
| Ctrl/⌘ + S | 导出当前画布 JSON |

### 左栏

| 按键 | 作用 |
| --- | --- |
| ↑ / ↓ | 切换对话列表选中项 |
| Enter | 打开选中对话 |
| F2 | 重命名选中对话 |
| Delete | 删除选中对话（二次确认） |

### 画布

| 按键 | 作用 |
| --- | --- |
| 空格 + 左键拖动 / 中键拖动 | 平移画布 |
| 滚轮 | 以指针为锚点缩放 |

## 七、状态机

节点状态：

```
draft ──提问──▶ streaming ──完成──▶ done ──删除本条──▶ draft
  ▲                                    │
  └──────────── 清空问题 ◀──────────────┘
```

右栏状态：`empty` / `active(node)`，`active` 内再按节点状态渲染三种视图。

连线状态：`idle` → `dragging(fromNode)` → `idle`（松手时校验端口与环路）。

## 八、数据模型（前端 TypeScript 定义）

```ts
type ID = string;

interface Workspace {
  canvases: Canvas[];
  activeCanvasId: ID | null;
}

interface Canvas {
  id: ID;
  title: string;              // 默认「新对话 N」
  createdAt: string;
  updatedAt: string;
  viewport: { x: number; y: number; scale: number };
  nodes: Node[];
  edges: Edge[];
}

interface Node {
  id: ID;
  title: string;              // 用户可改；初始化为首句问题截断
  position: { x: number; y: number };  // 世界坐标
  status: "draft" | "streaming" | "done";
  turn: Turn | null;          // 一个标签 = 一轮问答（V2 可扩展为 turns[]）
  createdAt: string;
}

interface Turn {
  id: ID;
  question: string;
  answerRaw: string;          // 原文，永不覆盖
  answerEdited: string | null; // 用户编辑后的文本；null 表示未编辑
  editedAt: string | null;
  model?: string;
}

interface Edge {
  id: ID;
  from: ID;   // 上游节点
  to: ID;     // 下游节点
}
```

持久化：V1 全部落 `localStorage`（键 `deepseek-canvas:v1`），任何变更 300ms 防抖写入。

## 十、后端接口契约（草案）

统一响应包：`{ ok: true, data: T }` / `{ ok: false, error: { code, message } }`。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/canvases` | 对话列表 |
| POST | `/api/canvases` | 新建对话 |
| PATCH | `/api/canvases/:id` | 改标题 / 视图位置 |
| DELETE | `/api/canvases/:id` | 删对话 |
| POST | `/api/canvases/:id/nodes` | 新建标签 |
| PATCH | `/api/nodes/:id` | 改标题 / 位置 / 状态 |
| DELETE | `/api/nodes/:id` | 删标签（级联删边） |
| POST | `/api/canvases/:id/edges` | 新建连线（服务端也要做环路校验，409） |
| DELETE | `/api/edges/:id` | 删连线 |
| POST | `/api/nodes/:id/turns` | 提问，返回 SSE 流 |
| PATCH | `/api/turns/:id` | 保存编辑后的回答 |
| GET | `/api/nodes/:id/context` | 返回组装好的上下文（调试/审计） |

流式接口：

```
POST /api/nodes/:id/turns
{ "question": "..." }

响应 200 text/event-stream
event: delta
data: {"text":"增量文本"}

event: done
data: {"turnId":"...","answerRaw":"完整回答","model":"..."}

event: error
data: {"code":"UPSTREAM_TIMEOUT","message":"..."}
```

注意：`EventSource` 不支持 POST，前端用 `fetch` + `ReadableStream` 自解析 SSE；`api.js` 已按此封装，Claude Code 不要改成 EventSource。

上下文由前端组装后随请求发送（`context: [{question, answer}, ...]`），后端只负责鉴权、限流、转发模型与落库；也可由后端按节点图自行回溯，二选一，V1 用前端组装以降低后端复杂度。

## 十一、边界与异常

| 场景 | 处理 |
| --- | --- |
| 空画布 | 中央引导文案 + 新建入口 |
| 生成中删除该节点 | 先中止流，再走删除确认 |
| 生成中切换节点 | 流继续，切回时继续渲染（状态存在节点上） |
| 生成失败 / 超时 | AI 气泡变错误态，提供「重试」，节点回 `draft` |
| 连线成环 | 拒绝并提示 |
| 节点过多（>200） | 关闭非选中节点的阴影与连线动画，保证帧率 |
| 标题超长 | 单行省略，hover 显示全称 |
| 浏览器窗口过窄 | 右栏折叠为抽屉（V2） |
| 本地存储损坏 | 解析失败时降级为空工作区并提示，不白屏 |

## 十二、V1 / V2 切分

**V1（本次交付）**：三栏布局、画布平移缩放、节点增删改、连线与成环校验、右键删除确认、右栏三态、mock 流式回答、回答编辑与上下文组装、localStorage 持久化、键位表全部落地。

**V2**：多轮标签（一个节点多次问答）、撤销重做完整栈、搜索与迷你地图、分支对比、导出 Markdown、右栏抽屉、协作与在线存储。

## 十三、三个关键假设（已确认）

1. **上下文范围**：取"全部上游祖先 + 拓扑序"，而不是只取一跳邻居。依据是你的原话「前面一切和他所链接的所有标签会话」。
2. **一个标签 = 一轮问答**：同一标签内不做多轮追问；要继续追问就新建一个下游标签。这样"每一次对话"才是画布上的一个节点。
3. **节点移动**：保留你指定的 Ctrl + 中键拖动，同时额外支持左键直接拖节点（端口仍只用于连线），因为 Ctrl+中键对触控板用户不可用。
